# Rama de riesgo — demostración opcional

`01_modelo_riesgo_demo.ipynb` conserva el prototipo previo con datos sintéticos.
Su primera celda tiene `EJECUTAR_DEMO_RIESGO=False` y se detiene expresamente.
Para explorar la simulación, cambiarlo a True y ejecutar las celdas en orden.

No es un paso obligatorio para entrenar YOLO26. Faltan datos climáticos reales,
etiquetas independientes y una comparación temporal con objetivos alineados.
La etiqueta sintética utiliza el umbral del baseline; métricas perfectas no
acreditan capacidad predictiva real. Las entradas de visión también son simuladas.
