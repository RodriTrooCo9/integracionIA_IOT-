## Optuna
: Framework de optimización de hiperparámetros con algoritmo TPE (Tree-structured Parzen Estimator). Automatiza la búsqueda de ganancias óptimas minimizando métricas integrales como IAE/ITAE en segundos (Gratuito, MIT).
## python-control
: Paquete de Python para análisis de sistemas de control en el dominio de Laplace y espacio de estados, facilitando el cálculo de márgenes de fase y retardo de Padé (Gratuito, BSD).
## SciPy Optimize
: Módulo de optimización numérica que permite ajustar curvas no lineales complejas mediante el algoritmo Levenberg-Marquardt en una sola línea de código (Gratuito, BSD).
## Google Colab
: Entorno interactivo en la nube que permite ejecutar el cuaderno de simulación y compartirlo directamente con el asesor de tesis sin requerir instalación local (Gratuito con cuenta Google).

## CVAT (Computer Vision Annotation Tool)
: Herramienta web de código abierto para anotación de imágenes y video con soporte nativo de exportación en formato Ultralytics YOLO (Gratuita, de código abierto).
## Roboflow
: Plataforma para control de versiones de datasets de visión, etiquetado colaborativo y exportación directa con generación de data.yaml (Nivel gratuito disponible).
## Albumentations
: La biblioteca más rápida y flexible de Python para aumentos fotométricos y geométricos de imágenes preservando coordenadas de bounding boxes (Gratuita, MIT).
## AutoDistill / Grounding DINO
: Framework para etiquetado automático en lenguaje natural mediante modelos fundacionales para pre-anotar miles de imágenes sin intervención humana (Gratuito, Apache 2.0).
